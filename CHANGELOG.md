# Changelog

Newest first. Older changes are in the git log.

## 2026-11-20
- **Process diagnostics.** `GET /api/procs` (pairing token required) lists the app's processes from Electron (`pid`, type, name, start time, CPU, memory) and every open web page or view with the process it runs in, so a pile-up of renderer helpers can be traced to the window that made it without restarting the app with a debug port.
- **Terminal tabs show the session name.** The tag next to a tab said "Mac mini · command session" and squeezed the name to "GCX …". It now says only the Mac (plus Hermes / script / helper when it isn't a normal session; the full text is in the tooltip), the name keeps at least 9 characters and the tag gives way first, and tabs may be 300 px wide (was 260).
- **Version 1.2.1: lighter while open.** The iPhone page no longer loads the mesh engine it stopped drawing on 11-15 (13 scripts and the three.js 3-D models): it now loads 7 scripts instead of 21, through a small stand-in (`phone/phone-viz.js`). On the Mac: the idle screen saver is off unless you tick it in View ▸ Mesh (its once-a-second idle poll stops too); the Live panel stops polling its job and its Chrome screencast while the panel is closed or the window is hidden; the All sessions list reloads every 60 s and not while hidden (was 20 s); countdowns skip hidden windows; the folder-stall check runs every 60 s (a slow call still flags a folder at once) and the memory popover's process list every 2 min.
- **Folder mirror stays small.** The iCloud viewing copy (`folderMirror`) now skips media work products (frames, upscales, renders, masters, video and audio, caches), caps files at 10 MB and each folder at 1 GB after filters (bigger folders aren't mirrored), and mirrors exactly with `--delete`, so pruned or skipped files leave iCloud too. Edits made in the copy are lost on the next pass. Before this, one project's upscale frames filled 12 GB of iCloud Drive and stayed there after the originals were pruned.
- **Sessions that run a skill get its folder.** A session started in the home folder that works through a hidden link (`~/.claude/skills/<name>` → the real skills folder) had no project folder, so no folder button and no Code map. Paths through a hidden link now count as the real folder they point to. Checked on 15 live sessions: three that had no folder now get their skill folder; every other session's folder is unchanged.

## 2026-11-19
- **Version 1.2.0: iPhone pages follow your finger.** The screens sit in a row: session drawer ↔ Sessions ↔ Grid. Moving between Sessions and Grid now tracks the finger 1:1 like the drawer, with the next screen sliding in beside it. On release it springs on past about 35 % of the width or on a flick, otherwise it springs back. The drawer and the pages share one curve and one threshold, and the spring is shorter the faster you swipe. Taps that change the page (☰ on Grid, a Grid card, the drawer's Grid link) slide the same way. GPU transforms only, written once per frame. Reduce Motion gets a quick fade.
- **iPhone terminal never scrolls sideways.** When another device holds the session size (a wider grid), the phone now shrinks the font until the grid fits the screen exactly (measured, no minimum). The session's real width is unchanged; touching the terminal still takes the size at the readable font, as before. The terminal box is `overflow-x: hidden` + `touch-action: pan-y`, so every sideways swipe over it goes to page navigation. The key row (Esc/Tab/arrows) scrolls only inside itself and never switches pages. Fixed: the terminal's side padding made it 8 px wider than its box.
- **Claude Code symbols as plain text (iPhone and Mac).** ⏺ was drawn as a colour emoji on iOS (a blue box with a white circle). Terminals now show it as ● in Claude Code's own colour (grey/white, green while working, red on error), and the other symbols that can turn into emoji (⏸ ⏹ ⏵ ✔ ⚠ ➡ …) get the text-presentation selector. Fonts fall back to Apple Symbols / Hiragino Sans before any emoji font, plus `font-variant-emoji: text`. Display only: the session's text is unchanged. Emoji in Claude's answers (✅ ❌ ⭐) stay as they are.
- **iPhone: the drawer belongs to Sessions only.** On Grid, the drawer no longer slides in over the cards: a right swipe, even from the edge, goes back to Sessions, and ☰ goes to Sessions. Sideways scrollers (the key row, wide content) keep the drag until they can't scroll further; a swipe from the left edge always switches. A gesture also survives the element under the finger being re-rendered (the drawer could stall half-open). The drawer list shows the **sun** / **duplicate** tag.
- **Version 1.1.0: the sun.** The session that runs the app is the mother star: fixed in the middle, larger, warm halo, its name, status, last activity and relays today above it. Click the star to open it (right-click for the star menu). Duplicates of its name are labelled **duplicate**; the real one is the current generation of its handoff lineage.
- **Relays.** Messages between sessions are counted (⇄ N today in the list, Simple board and iPhone list/Grid) and drawn on the mesh as 4-second beams between sender and receiver. The mesh only animates while a beam is showing; Reduce Motion gets still beams.
- **Per-project refresh steps.** `extra` entries in `local/session-refresh.json` take `first`, `after` and `flush` (see README). A flush that isn't confirmed in time skips that day's refresh and alerts you. `cwd` starts the new generation in the project folder; `verifyFiles` puts three questions from those files into the verification.
- **Refresh skips say why.** A "you are typing in Mesh" skip now names the source: keyboard/mouse on this Mac, or Mesh input from this window, a remote terminal or a send (with its address and first bytes). The 11-19 night still skipped most sessions after the typing fix; the log will show what keeps the input clock young.

## 2026-11-18
- **Nightly refresh no longer thinks you're typing.** The whole 11-18 night refresh skipped every session with "you are typing in Mesh". Terminal-made bytes (mouse reports while a keep-awake jiggler moved the cursor, focus and device-attribute replies), size claims and local script sends counted as typing. Now only real keys from this Mac, the other Mac or the phone, and sends from another device, do.
- **Terminal size from another device, fixed.** Opening a terminal tab last sized by the other Mac or the phone now takes this window's size right away, without a scroll first. Keys typed while it changes size wait until Claude Code has redrawn (at most about 1.2 s), so the text no longer lands over the old layout.
- **iPhone: swipe to the board.** Right to left shows the session board (Grid), and left to right on the board goes back, like the Mac window. Left to right anywhere else still opens the drawer.
- **iPhone drawer swipe from anywhere.** A swipe to the right opens the session drawer from anywhere, over the terminal too, with a parallax drawer and a smoother snap. The terminal font is crisper (system monospace) with a little more line spacing.
- **Swipe to the session board.** A two-finger swipe from right to left over the Mesh shows the session board (Simple view). Left to right brings the Mesh back.
- **View-only machines.** `peer.json` can list several machines (`mode: "full"` or `"view"`). The old single-peer format still works. View machines (`kind: "ssh-gate"` over an SSH gate, or `kind: "http"`) show their sessions as cards with **Send** and **Stop job** only. They get no terminal, transcript, resume, move or sync. See README → View-only machines.
